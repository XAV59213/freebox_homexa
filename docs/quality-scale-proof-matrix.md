# Matrice de preuves — autoévaluation locale, pas certification

État du lot 5 : **13 done / 39 todo / 2 exempt**, version préparée **28.8.90**.
Chaque ligne reprend une des 54 règles de la source HA épinglée dans
`quality_scale.yaml`. Le lien mène à sa règle officielle ; le minimum ci-dessous
est une condition de validation entière, **pas un plan pour cocher le score**.
Les preuves détaillées fichier/fonction/test sont dans le YAML et
[le rapport d’audit](quality-scale-audit.md).

## Comment poursuivre sans confondre les blocages

1. **Travail local compatible restant** : setup/rollback partiel et inventaires globaux,
   disponibilité partielle, lifecycle simultané/setup partiel, ajouts dynamiques,
   catégories/classes/defaults et typage. Pas besoin de matériel pour les contrats
   et le cycle HA ; matériel nécessaire pour prétendre une compatibilité physique.
2. **Choix de compatibilité à préparer** : identité host/MAC/jeton, noms historiques,
   regroupements Home, retrait d’appareils persistants et dépréciation du polling
   configurable. Proposition + tests migration/rétablissement avant changement.
3. **Limite SDK vérifiée** : pas d’injection publique et close non garanti dans
   certains échecs. Aucune session privée ni dépendance externe modifiée.
4. **Documentation** : les treize critères todo ont du contenu local ; leur réserve
   formelle n’est pas un manque général de documentation. La matrice matérielle
   reste limitée aux preuves disponibles. Aucune soumission home-assistant.io,
   brands, commentaire ou certification n’est faite par cette PR.
